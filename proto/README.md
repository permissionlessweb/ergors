# Ergors Protocol Buffer Definitions

This package contains Protocol Buffer definitions for the ERGORS (CommonWare Host Orchestrator) system, organized into two main layers following the sacred geometry principles:

## 📦 Layers

### Storage Layer (`storage/v1/`)

### Orchestration Layer (`orch/v1/`)

### Network Layer (`network/v1/`)

## 🔄 Generation

To rebuild type definitions:

```bash
# From project root (recommended)
just proto

# Or manually from proto directory
cargo run
```

### Vendoring External Dependencies

Some proto dependencies (like `k8s.io/apimachinery` for Akash types) are vendored via Go modules:

```bash
# Vendor dependencies
just modvendor

# Or manually
cd proto && go mod tidy && go mod vendor
```

**Files:**
- `go.mod` - Declares external dependencies (e.g., k8s.io/apimachinery)
- `vendor.go` - Dummy Go file to trigger vendoring
- `vendor/` - Auto-generated by `go mod vendor` (gitignored)
